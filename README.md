# Файлы для итогового задания

Веб-сервер, который реализует функциональность планировщика задач — это аналог TODO-листа

API содержит следующие операции:
 - добавить задачу;
 - получить список задач;
 - удалить задачу;
 - получить параметры задачи;
 - изменить параметры задачи;
 - отметить задачу как выполненную.

---------------------------------------------------------------------------------------------------
Список выполненных заданий со звёздочкой:

 - Реализуйте возможность определять извне порт при запуске сервера
 - Реализуйте возможность определять путь к файлу базы данных через переменную окружения
 - возможность выбрать задачи через поиск
 - Аутентификация
 - Создание докер-образа

Запуск из Docker происходит командой:
$ docker build -t todo:latest .
 $ docker run -v $(pwd)/scheduler.db:/app/scheduler.db -e TODO_PORT=8080 -p 8080:8080 todo

---------------------------------------------------------------------------------------------------
Проект запускается по go run . из корневой папки.

Переменные заданы в .env:
    Порт 8080. После запуска проект доступен по http://localhost:8080/
    Аутентификация http://localhost/login.html. Пароль albatross6-send-married

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Структура проекта:

```
├── pkg
│   ├── api
│   │   ├── addtask.go        # Функции обработчика добавления задач
│   │   ├── api.go            # Запуск маршрутов через http.HandleFunc
│   │   ├── nextdate.go       # Функция вычисления следующей даты задачи по правилу (*реализация 'w', 'm' отсутствует)
│   │   ├── signin.go         # Аутентификация: middleware + обработка POST-запроса на /api/signin
│   │   ├── task.go           # Обработчик /api/task. Поддержка методов GET, POST, PUT, DELETE
│   │   ├── tasks.go          # Обработчик GET-запроса /api/tasks
│   │   └── writeJson.go      # Универсальная функция для ответа в формате JSON
│
│   ├── db
│   │   ├── db.go             # Инициализация базы данных, создание схемы и таблиц (путь к БД задаётся через переменную окружения, настраивается в main)
│   │   └── task.go           # Функции для работы с задачами в базе данных
│
│   └── server
│       └── server.go         # StartServer: запуск веб-сервера (*порт может задаваться через переменную окружения)
```
